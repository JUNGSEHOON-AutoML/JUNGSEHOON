CCIFPS — Class-conditioned Feature Patch Selection

정상 이미지의 특징을 저장해 결함 위치를 찾는 검색 기반 이상탐지에서, 비슷한 정상 패치가 중복 저장되는 문제를 다뤘습니다.

목적

중복 저장을 줄이면서 정상 패턴의 대표성과 탐지 성능을 검증

본인 역할

특징 선별 로직 구현, 클래스별 조건 비교, 결과·오류 분석

접근

거리 가중 확률 선택 + 코사인 거리 임계값 기반 중복 제거

지도교수의 k-means++ 초기 중심 선택 원리 응용 제안을 바탕으로 실제 알고리즘을 구현하고, MVTec AD 15개 클래스에서 Pixel AP·F1·저장량·실행 비용을 비교했습니다.
