01 / INTENT

실제 설비 없이 공정 조건을 비교하기 위해

석사 연구의 이상탐지 모델이 검사뿐 아니라 이송, 재검사, 처리량과 대기열에 어떤 영향을 주는지 알고 싶었습니다. 실제 공장의 공정 데이터와 장비에 접근하기 어려워 디지털 트윈 기반의 가상 공정을 기획했습니다.

Claude는 명세·오류 분석에, Codex는 저장소 조사·구현·테스트에 활용했습니다. 저는 입력 데이터, 비교할 공정 정책, 실행 예산, 통과·중단 기준을 정하고 생성 코드와 실험 결과를 검증했습니다.

02 / FIRST VERIFICATION

문서와 다른 알고리즘을 실제 호출 경로에서 발견

첫 검사 모듈은 연구 특징 선별기를 사용한다고 설명되어 있었지만, 실제로는 정상 특징 4,000개를 무작위 저장하고 있었습니다. Codex로 코드 호출 경로를 추적해 실제 선별기를 연결하고, 선택 인덱스와 원본 이미지 패치 위치·소스 해시를 저장하도록 수정했습니다.

83 images정상 20 · 결함 63
용기(BOTTLE) 고정 평가
4 → 1같은 K=10,500 조건
무작위 대비 결함 미탐
0 / 0두 방법 모두 정상
오탐 건수 0

정상 이미지 209장은 메모리 뱅크 구성용 167장과 임계값 보정용 42장으로 분리했고, 시험 이미지 83장은 임계값 조정에 사용하지 않았습니다. Pixel AP는 같은 K의 무작위 방식보다 소폭 낮아진 수치도 그대로 기록했습니다.

03 / INVALID RUNS

잘못된 공정 모형의 322개 결과를 무효화

이후 별도 이산사건 시뮬레이션에서는 정책 A가 AI 판정 후 본 라인으로 처리하고, 정책 B는 NG 제품을 오프라인에서 재검사하는 구성을 비교했습니다. 그런데 재검사 입구에 잘못 적용된 유한 버퍼가 원래 본 라인을 차단하지 않아야 하는 B 정책에서도 생산 흐름을 막는 오류가 있었습니다.

기존 완료 결과 322개를 무효 처리하고, NG를 오프라인 무제한 FIFO에 즉시 인계하도록 계산 계약을 고쳤습니다. 공정 소스의 불량률은 5%라는 가정으로 지정해 복원추출하고, 정답 레이블이 모델 판정에 유입되지 않도록 검증했습니다.

04 / RUN BUDGET

실행과 사후 계산을 분리해 실험을 완료

수정된 조건에서는 예상 실행 시간이 8시간 예산을 넘어섰습니다. B는 A의 본 라인 생산·검사 기록을 바꾸지 않으므로, A를 직접 시뮬레이션하고 B의 재검사·처분은 검증된 A 저장 기록에서 계산하도록 분리했습니다.

2,970고유 A DES 결과
기존 유효 15회 포함
4,320B 사후 계산 결과
B DES 별도 실행 0회
6.03 h본 실행 단계의
실측 소요 시간

13.49시간은 수정 전 구조를 기준으로 한 예상치이고, 6.03시간은 변경된 구조에서의 본 실행 시간입니다. 같은 구현을 전후 실측해 몇 배 빨라졌다고 주장하지 않습니다.

05 / RESULT & BOUNDARY

연구 결과를 탐색하는 웹 프로토타입

공정 실행 기록을 3개 검사 홀·9개 비교 레인에서 재생하고 근거 이미지를 확인할 수 있는 화면으로 연결했습니다. 최종 보존된 검증 기록에서 백엔드 테스트 267개 통과·3개 미실행, 고정 검증 결과 차이 0을 확인했습니다.

이 프로젝트는 가정값을 이용한 연구용 시뮬레이션입니다. 실제 공장에 설치한 생산 최적화 시스템이 아니며, CPU Live 검사는 당시 BOTTLE CCIFPS 일부 구성에 한정됩니다. 웹 Replay와 실제 추론 Live를 구분합니다.
