UNDERGRADUATE / CAPSTONE DESIGN

데이터가 없던 문제를
어종 판별 앱으로 연결하다.

데이터 수집·정제와 반자동 라벨링부터 모델 학습, Flask API 연동, 실제 시장 이미지에서의 실패까지 이어진 3인 팀 캡스톤 프로젝트.

YOLOv4Computer Vision3-person team2023
01 / ORIGIN

어떤 생선인지 사진으로 확인할 수 있을까?

학부 캡스톤에서 팀원들과 회를 먹다가 어종을 두고 의견이 갈린 경험을 시작점으로 삼았습니다. 모바일로 생선을 촬영해 어종을 판별하고 관련 정보를 보여주는 앱을 기획했습니다. 3인 팀에서 두 팀원은 Flutter 앱과 Spring Boot API·DB를 담당했고, 저는 사진 데이터 구축·YOLOv4 학습·Flask 추론 API를 맡았습니다.

02 / DATA PIPELINE

데이터셋부터 만들었습니다

네이버·Google·Instagram에서 어종 이름으로 이미지를 모았지만 어부와 찍힌 사진, 식사 장면처럼 무관한 이미지가 많이 섞여 있었고 객체 위치 라벨도 없었습니다.

  • 이미지를 특징 벡터로 바꿔 유사 장면끼리 묶고 무관한 그룹을 제거했습니다.
  • OpenCV로 색상과 윤곽선을 살펴 생선이 있을 법한 영역을 추정했습니다.
  • 일부 이미지에는 LabelImg로 수작업 라벨을 만들고 YOLOv4를 1차 학습했습니다.
  • 이후 높은 신뢰도의 예측을 라벨로 활용하고 애매한 결과는 다시 검수하는 과정을 반복했습니다.
03 / SERVICE & FINDINGS

모델을 앱에서 쓰려면 무엇이 부족할까?

Flask 추론 API를 팀원들의 앱·Spring Boot 서버와 연결해 사진 전송과 판별 결과가 돌아오는 프로토타입을 만들었습니다. 입력부터 결과 반환까지 처리 시간을 나눠 보니 모델 추론 구간이 약 7초로 주요 병목이었습니다.

또한 수산시장에서 촬영한 연어 사진은 잘못 분류했습니다. 수집한 웹 이미지가 실제 촬영 환경을 충분히 반영하지 못한 한계가 있었습니다. 연구 지표뿐 아니라 서비스 사용 환경과 데이터 분포를 검증해야 한다는 점을 확인했습니다.

시세 정보 제공은 기획 목표였습니다. 본인의 담당 범위는 데이터 구축·모델·Flask 추론 API이며, 앱·일반 서버는 팀원들이 맡았습니다.
